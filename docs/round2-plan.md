# 新人课程实施计划

**目标：** 从全局导读、入口生命周期到功能课程，保留可复现的分组和机械校验。
**实现方式：** 在当前干净的 `repo-tutor/` 和 `round2-course` 分支内顺序执行；不创建额外 worktree，不委派代理。以本任务书的自主执行授权完成实现、提交和 PR。

## 边界与条件矩阵

- 扫描仍为 AST 只读，不执行输入仓库；补充协议入口识别与公开类构造入口。
- 原公开符号和入口必须恰好归属一个功能课；00 导读只引用代表节点，不改变归属。
- 同模块、同最近路由/协议入口的节点聚类；构造器与 CLI 留在模块功能组；调用/继承边用于课程拓扑，import 边用于模块图；跨组环作为共同先修，稳定排序；大组按 SCC 单元拆分，环不可拆。
- 模型只命名和讲解，不能移动节点、编辑依赖、编造图节点。旧计划拒绝复用，避免静默沿用旧分组。
- 两至三个目标、按调用顺序的连续段落、程序生成的速查表、两道带答案和引用的自测、下一课衔接。
- 每课程序画图；校验声明和边端点必须对应扫描节点，额外图语法保守拒绝。覆盖只认有效源码引用，分开统计正文与仅表格。
- 原引用、覆盖、源码漂移、预算持久化和只读 MCP 保持；失败、超预算和过大上下文不自动重试。
- Flask 3.1.2，真实 DeepSeek 总调用不超过 25；不改可见性，不注册 runner，不合并 PR。

## 文件与测试顺序

1. `tests/test_course_groups.py` / `scanner.py` / 新 `curriculum.py`：先写入口、模块纯度、稳定性、恰好一次归属、组拓扑与环测试并确认失败。实现 `group_lessons(inventory, limit)`，输出固定节点归属、入口与阅读顺序；返回可重算的 schema v2 计划骨架。
2. `tests/test_generation.py` / `course.py` / `model.py` / 新 `diagrams.py`：假模型端到端覆盖 00 与功能课结构、多个符号的连贯段落、引用白名单、错误模型输出、源码漂移拒绝。模型返回 goals / paragraphs / quiz / transition；程序统一附引用与图表。保留源码证据长度和调用预算约束。
3. `tests/test_verify.py` / `verify.py`：先覆盖伪造图节点、未声明端点、空图、缺课文结构、速查表与正文分类、无效引用不能计覆盖。实现图节点身份检查和细分覆盖报告。
4. CLI 假模型 all / resume / 00 选择 / plan 失配测试；`cli.py` 复用既有命令链，不增模型调用入口。
5. 本地 pytest、ruff、build；固定 Flask checkout 真实生成，最多 1 次命名 + 23 个课文请求，原始响应只留任务目录。替换示例为 00 + 两个流程课，分别校验完整输出与示例子集。
6. README 首屏真实 00 节选，更新配置、分组算法、静态推断限制和 CI 状态；最终 diff、敏感信息、干净安装与 CLI/MCP 检查后提交、推送和创建 PR #2。回读 PR、检查 CI、写任务目录报告、最后创建 DONE-r2。
